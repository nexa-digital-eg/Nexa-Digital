# Nexa Digital

موقع عربي RTL احترافي لعلامة Nexa Digital مبني باستخدام Next.js وTailwind CSS، ومجهز للتحويل إلى عملاء عبر واتساب.

## معاينة التصميم

- يمكن فتح ملف المعاينة البصري `public/nexa-digital-preview.svg` في المتصفح لرؤية شكل الصفحة المقترح: الهيدر، الهيرو، كروت الخدمات، تركيز السيستم المخصص، وزر واتساب العائم.

## التشغيل المحلي

```bash
npm install
cp .env.example .env.local   # ثم عدّل القيم
npm run db:init              # ينشئ الجداول ويملؤها من data/site.js (مرة واحدة)
npm run dev
```

افتح `http://localhost:3000`.

## اختبار الإنتاج

```bash
npm run build
npm run start
```

## قاعدة البيانات (Neon) ولوحة الإدارة

الخدمات والباقات تُقرأ من قاعدة بيانات Neon Postgres، وتُدار من لوحة تحكم محمية.

### متغيرات البيئة المطلوبة

| المتغير | الوصف |
| --- | --- |
| `DATABASE_URL` | سلسلة اتصال Neon Postgres (تبدأ بـ `postgresql://...sslmode=require`). |
| `ADMIN_PASSWORD` | كلمة مرور الدخول إلى `/admin`. استخدم قيمة قوية وخاصة. |

> القيم الحساسة توضع في `.env.local` محليًا (مستثنى من Git)، وفي **Vercel → Project Settings → Environment Variables** للنشر.

### تهيئة الجداول

```bash
npm run db:init
```

ينشئ جدولي `services` و`packages` ويملؤهما بالمحتوى الافتراضي من `data/site.js` إن كانا فارغين.

### لوحة الإدارة

- الرابط: `/admin` (يحوّل إلى `/admin/login` لإدخال `ADMIN_PASSWORD`).
- يمكن إضافة/تعديل/حذف الخدمات والباقات، وتظهر التغييرات على الموقع خلال ~30 ثانية (ISR).
- إذا لم تُضبط `DATABASE_URL`، يعرض الموقع المحتوى الافتراضي من `data/site.js` دون أعطال.

## ملاحظات Vercel

- المشروع يستخدم App Router داخل مجلد `app`، وينشر مباشرة على Vercel بعد ربط المستودع.
- أضف `DATABASE_URL` و`ADMIN_PASSWORD` في إعدادات البيئة على Vercel قبل النشر.
- بعد أول نشر، شغّل `npm run db:init` (محليًا بنفس `DATABASE_URL`) لإنشاء الجداول.
- رقم واتساب ورسالة التواصل موجودان في `data/site.js` ويمكن تعديلهما بسهولة.

## تحسينات مستقبلية مقترحة

- إضافة صور أعمال حقيقية بدل بطاقات الـ placeholders.
- إضافة نموذج تواصل متصل بقاعدة بيانات أو CRM.
- إضافة صفحات تفصيلية لكل خدمة لتحسين SEO.
- توسيع لوحة الإدارة لتشمل الأعمال السابقة وآراء العملاء والأسئلة الشائعة.
